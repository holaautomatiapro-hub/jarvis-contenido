# Bienvenido a tu vault de JARVIS

Este vault es la memoria de JARVIS. Todo lo que capturas en el dashboard o mandas por Telegram acaba aquí como notas de Markdown normales, así que también puedes escribir y editar en Obsidian.

- **[[_voz]]**: tu perfil de voz. JARVIS lo usa para escribir como tú.
- **01-Ideas**: tus ideas de contenido.
- **02-Guiones**: guiones listos para grabar.
- **03-Transcripciones**: lo que ya has publicado, en texto.

Puedes reorganizar las notas como quieras, pero mantén los nombres de las carpetas principales: el dashboard los usa.
